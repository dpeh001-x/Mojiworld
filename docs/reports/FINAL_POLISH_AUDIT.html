1. The final polish pass: high impact, small effort (18)

findingimpact · effortevidence → fix
F1A new player is never pointed at Act I: the tracker is empty, then names a Lv 20 quest ✓ verifiedHIGH S
Runtime: a fresh Lv 1 warrior after the prologue stands in the Void with no quest unlocked or active and an empty tracker. Code: the tracker's "Next" row walks _QUEST_STORY_CHAIN (62755), which starts at q_inner_dim_trial (Mirror Self Trial, Lv 20); the six Act I story quests (q_act1_*) are not in it, so once it renders it reads "🌅 Next: Mirror Self Trial · Lv 20".
→ Lead the chain with the six q_act1_* ids (or pick the lowest-level unfinished story quest), and render the tracker when the tour closes.
F2The first quest stays hidden until the player opens the journal or levels up ✓ verifiedHIGH S
quests.unlocked is written only in tickQuestUnlocks (56668), called on quest completion, journal open, level-up and by Milo - not after class pick or the prologue. Nurse Joyce's Accept row and "!" need it; the Void and town have no spawns, so there is no early level-up either.
→ Call tickQuestUnlocks() after applyClass / the prologue, and end the tour with "Talk to Nurse Joyce in the Everdawn Megamall".
F3The hero's name is asked twice, and the first answer is dropped ✓ verifiedHIGH S
Runtime: typed "Tester" at the title's "Name your hero"; the character creator then showed an empty NAME field (#hero-name-input value "", placeholder "Hero") while player.look.name was already "Tester", and Guguma says "Pick a real name". The creator field also allows 14 characters, the gate 16.
→ Pre-fill #hero-name-input from player.look.name when the creator opens (or drop the gate's name step), and match the length limits.
U1Steam build: Electron's default menu is live - Alt shows File/Edit/View, Ctrl+R reloads, Ctrl+W closes the game ✓ verifiedHIGH S
steam/main.js never calls Menu.setApplicationMenu(null); the window only sets autoHideMenuBar: true (158). No Alt+Enter / F11 handling; the window always opens at 1280×800 and does not remember size, position or fullscreen.
→ Menu.setApplicationMenu(null); save / restore window state; Alt+Enter and F11 via before-input-event → win.setFullScreen.
U2Bulk sell can sell equipped gear with no confirm and no buyback ✓ verifiedHIGH S
"Select all" (108772) adds every inventory index - equipped items live in the inventory array - although the tier filter deliberately skips them (108373). Sell (108817) runs executeSellSelection, which unequips and sells (108397).
→ Leave equipped / legendary items out of Select all; confirm when the selection holds any; buyback of the last 10 sales.
U3Salvaging a set item is one click, equipped pieces included, and loses its stars ✓ verifiedHIGH S
The salvage list includes equipped set pieces (110327); the button calls _disassembleSetPiece directly (110353). Plain discard already warns about stars (114845).
→ Reuse the discard uiConfirm with the star warning and an "(equipped)" note.
U5The fullscreen button needs two presses after a relaunch or after leaving fullscreen with Esc ✓ verifiedHIGH S
toggleFullscreenDesktop (42615) keys off a saved "force desktop" flag restored at boot (42648), not document.fullscreenElement; _syncFullscreenIcon swaps the painted icon for text (42657).
→ Decide from document.fullscreenElement; keep the layout flag separate.
B1Killing Gravitos (and Octobaby) shows Aetherion's victory lines: "THE SHARDFATHER FALLS!" ✓ verifiedHIGH S
_triggerSuperBossDeathRaw runs for every superBoss (101104) - Gravitos and Octobaby are super bosses (26860, 26866) - and always toasts "THE SHARDFATHER FALLS!" / "The Sanctum trembles..." (101761).
→ Pick the lines by boss type (Gravitos: his own fall; Octobaby: hers).
B2Pisces' Tidal Crush (26% max HP) is promised a 1 s warning and gets ~46 ms ✓ verifiedHIGH S
_tidalT = 60 (147374) is counted down with the handler's dt in ms (147380); the comment says "1s later" (147370). The only tell is a shrinking particle ring.
→ _tidalT = 1000, scale the ring to it, draw a zone marker.
B3Flat %-max-HP moves can lose their warning lane (Legosaurus's gore, the Arbiter's VERDICT) ✓ verifiedHIGH S
The lane draws only if _lxZoneWorthy passes (149093), which compares the boss's ATK to the player's HP; the hit is a flat share of max HP (88935). Leo's pounce is already exempted for this reason (149115).
→ An "always draw" flag for flat-percentage moves.
B4A Gemini / Pisces split replays the boss entrance banner; killing the twin plays the boss-kill beats ✓ verifiedHIGH S
The twin is spawned as a boss (145113, 147478) → the spawn banner with shake 8 / flash 0.5 fires mid-fight (72069). The twin's death runs the kill slow-mo (100641) and "…defeated! Choose a powerup!" (101217) though no boon follows.
→ Skip the banner for a split spawn; skip slow-mo and toast for _lxTwinKill.
A1Every class speaks with the warrior's voice; 24 mage / rogue / archer voice files never play ✓ verifiedHIGH S
_classKey() reads player.class (159245), a field nothing ever sets (the class lives in player.cls), so it always falls back to warrior.
→ Read player.cls; map rogue → thief, archer → bowman.
C1Struck enemies never show their white hit flash during hit-stop, and only for ~1 frame after ✓ verifiedHIGH S
hitMonster sets m.hitFlash = 50 (99103); the draw shows it only when floor(hitFlash / 30) % 2 === 0 (140753), false at 50; hitFlash counts down only in updateMonsters (88281), which is frozen during hit-stop. On bosses, which barely squash, the flash is nearly the only sign a hit landed.
→ Draw the flash for the whole hitFlash > 0 window (or time the blink from the hit).
C2Most skills - 13 of 17 ultimates - land with a basic attack's weight ✓ verifiedHIGH S
_lxSkillImpact(skill) picks the hit-stop tier from SKILLS[skill].cd (97575) but is called with the hit's TAG (99150): 'meleeSkill', 'aoe', 'fire', 'shard'… which are not skill ids, so the tier is 0 (35 ms, no flash). Only ~19 of 72 skills pass their own id. E.g. doombringer_ult, hexmaster_ult finale, sage_ult comets, phantom_ult shards, dragoon_ult.
→ _lxSkillImpact(_rankSrc || skill) - the cast skill is already known there; rate-limit to the first hit per cast every ~250 ms.
C3Enemies play their pain sound on MISS, IMMUNE, BURROWED and SHROUDED ✓ verifiedHIGH S
_playMonsterSfx(m, 'hit') (98486) runs before the early exits at 98501 / 98527 / 98536 / 98627; bosses dodge up to 45%, so many "MISS" popups come with the boss's pain clip.
→ Move it next to the hit sound (99180); a dull whiff for misses.
R1Twelve maps' backgrounds are stretched ~29% sideways ✓ verifiedHIGH S
Eleven plates are 4:3 (2464×1856, measured: magmaFoundry, glasswindSteppe, wayfarersLantern …) - Withering Tide ×2, Magma Foundry ×2, Glasswind Steppe ×2, Hollow Sepulchre ×2 (+ Ossuary Sprawl), Wayfarer's Lantern ×3 - and are drawn straight into the W×H box (118715-118728); every other plate is ~16:9.
→ Cover-crop to the canvas aspect in the draw (S); extending the 11 plates to 16:9 is new art (M).
A2Ambient loops range from inaudible to as loud as the musicHIGH S
Measured (ffmpeg, loudest 400 ms): meadow.mp3 -56.5 LUFS (the only ambience on 4 maps), snow -37.1, glasswind -32.7, abyss -6.2 (≈ level with the music on abyssalTrench / octopusGrotto).
→ Normalise all 17 ambient loops to one target (~-24 LUFS); regenerate meadow.
R2Octobaby's four tentacles (Venom, Frostbite, Silence, Shock) look identicalHIGH S
Each has its own colour and status (monsterTypes 27101-27104) but the painted sprites are the same purple arm (image distance 0.6-2.3 vs 22.7 for the next-closest monster pair); the old procedural path gave each a colour and a ☠ ❄ 🔒 glyph (142762), the painted path (141061) draws neither.
→ Tint each sprite by type, or a coloured rim + the old glyph badge (S).
