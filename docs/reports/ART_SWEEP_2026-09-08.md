# Art sweep — 2026-09-08

Per user: "sweep through the art files in the game and see which ones are odd and suggest which
require replacement or regeneration."

**Scope:** every file under `Sprites/`, `backgrounds/`, `assets/` at `c12210c5` — 7,228 files (backups
and the `New background` PNG folder excluded), 639 animation sets. **Method:** each file decoded with
sharp and measured (canvas, alpha, ink box, ink on the outer 2 px ring per edge, corner alpha, body
sharpness as Laplacian variance at a common 320 px body height, a 9×8 dHash of the body); sets judged
on frame count/gaps, canvas consistency, body-height pulse, foot-line drift, centre jumps and
near-identical frames; references cross-checked against the runtime registries (`art_sweep_keys.mjs`),
the game source tokens and `audit_dead_assets`. Every set flagged below was then checked by eye on a
contact sheet, and the false positives are listed as such. Re-run: `node scripts/art_sweep.mjs out.json`,
`node scripts/art_sweep_report.mjs <dir>`, `node scripts/art_sweep_sheets.mjs <dir> <kind>`.
