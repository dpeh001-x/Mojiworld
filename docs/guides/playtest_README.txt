HOW TO START (Windows)
----------------------
1. Unzip this folder anywhere (Desktop is fine).
2. Double-click:  Mojiworld.cmd
3. The game opens in your browser. That's it.

A small console window opens and stays open while you play
— that's the local game server. Closing it stops the game,
so just leave it minimised.

Nothing needs to be installed. Everything required is in
this folder.


IMPORTANT
---------
Do NOT double-click "mojiworld_game.html" directly.

It will appear to work, but the browser blocks part of the
game from loading that way and the floor and platform
textures go missing. Always start with Mojiworld.cmd.


IF IT DOESN'T OPEN
------------------
* Windows may warn about an unrecognised app. Choose
  "More info" then "Run anyway". The launcher is a plain
  text file — you can open it in Notepad and read it first.

* If the browser doesn't open by itself, run Mojiworld.cmd
  and then go to this address manually:

      http://localhost:8765/mojiworld_game.html

* If it says the port is busy, close the old console
  window and try again.

* Chrome or Edge are recommended.


CONTROLS
--------
Arrow keys      move
Space           jump (press again mid-air to double-jump)
Z               attack
X S C D F V G   skills, unlocked as you level up
B               master ultimate (level 50)
A               block / parry
Shift           dodge roll

U               character panel — stats, skills, boons, bag
Q               quest journal        (J also works)
Y               codex — bestiary, lore, achievements
L               Mojidex — creatures you've encountered
W               world map
N               talk to the person you're standing next to
H               summon your MojiMon companion
K               view and rebind every key
M               mute / unmute
PageUp          drink a health potion
PageDown        drink a mana potion
Esc             close menus

A tutorial runs the first time you play and walks you
through the rest.


SAVING
------
Progress saves automatically inside the browser. Use the
same browser each time, and don't clear browsing data for
this site or the save goes with it.
