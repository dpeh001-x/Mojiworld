Start here

  1. The newest version of the game opens by itself (it needs the internet). If it does not, click ⟳ Newest game, or 📂 Open game file to choose a mojiworld_game.html yourself.
  2. Pick a class, find a skill, and type a new number into any box. Changed boxes turn gold.
  3. Open More options at the bottom, click 📋 Copy my changes, and paste them into a message to Claude.

The version you are editing is shown next to the title. 💾 Save to game file only writes into a game file of that same version, so a newer game is never mixed with an older copy.

What do the numbers mean?
× attack
Damage as a multiple of the player's attack. 1 = one attack's worth, 2 = double, 0.5 = half.
Extra flat damage
A fixed amount added on top, the same at every level.
How many
How many hits, shots, waves or summons the skill makes.
Pixels
Size or reach. The game screen is about 960 pixels wide.
Milliseconds
1000 milliseconds = 1 second. The box next to it shows the seconds.
Frames
60 frames = 1 second.
Measured damage
From the last damage test: 100% means one basic attack, 1000% means ten.
