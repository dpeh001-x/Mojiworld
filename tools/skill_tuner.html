Skill Tuner

Edit cooldown and MP for any skill, then copy the patch and bake it.
Cooldown and MP are real per-skill fields, so what you type here is exactly what the game will use. Damage is not a field — each skill computes its own numbers inside its function, at different times and through different paths, so there is no single number to edit. A universal multiplier was tried and measured: it moved the necromancer's vortex 6.3× for a requested 2× and the sage's columns 1.04×, so it was discarded rather than shipped. To change a skill's damage, edit the constant in its own SKILL_FNS entry.
